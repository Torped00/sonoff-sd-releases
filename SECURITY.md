# Security / Sécurité

Never post camera pairing files, account credentials, TLS keylogs, firmware dumps or private recordings in an issue. If you identify a vulnerability, report only a minimal non-sensitive description asking for a private reporting channel; do not publish working keys or personal data.

The local camera helper uses authenticated HTTP, not HTTPS. Keep it on a trusted local network. Do not port-forward the service or expose it directly to the Internet.

Ne publiez jamais de fichier d’association, identifiant de compte, keylog, copie de firmware ou vidéo privée dans un ticket. Pour une vulnérabilité, demandez un canal privé avec une description minimale sans données sensibles. L’accès caméra est réservé au réseau local de confiance ; aucun transfert de port vers Internet.
